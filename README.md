# ParkourGame

Браузерный прототип 3D-паркура на Three.js и Rapier. Модель персонажа — предоставленный `Y Bot.fbx`.

## Играть

**[Открыть игру](https://mnemonicsquare-cpu.github.io/Parkour_Game/)**. Для запуска по ссылке Node.js не нужен. После загрузки модели и анимаций нажмите «Играть».

## Управление

| Клавиша | Действие |
|---|---|
| WASD | Бег относительно камеры |
| Shift во время бега | Подкат |
| Space | Прыжок; повторно в воздухе — двойной прыжок с кувырком |
| F возле уступа | Захват края на земле или в воздухе |
| W или Space в висе | Подтянуться на крышу |
| S + Space в висе | Прыжок от стены |
| E в висе или при подъёме | Отпустить край |
| C возле края крыши | Спуститься в вис |
| R | Вернуться в выбранную зону |
| Esc | Меню и пауза |
| F3 | Диагностика, коллайдер и проверка клипов |

Мышь вращает камеру, колесо меняет дистанцию. Клавиша Ctrl свободна: режима скрытности нет. В меню доступны настройки механик, звука и клавиш, а также зоны для проверки бега, низких препятствий, подката, лазания, крыш и падения.

## Механики

- Движение, столкновения и контакт с поверхностями рассчитывает Rapier с фиксированным шагом 1/60 секунды. Персонаж использует кинематическую капсулу. Высота визуальной модели и физического коллайдера согласована с уровнем пола.
- WASD запускает бег с ускорением, торможением и плавным разворотом. Диагональное движение нормализовано. Основной клип бега — `New animation/Sprint.fbx`; его темп зависит от фактической скорости.
- Прыжок, двойной прыжок с процедурным кувырком, прыжок от стены, падение, кувырок при приземлении и тяжёлое приземление сохранены.
- Захват края требует подходящей высоты, дистанции, направления к стене, попадания луча в препятствие и свободного места на крыше. Низкие стены не запускают полноценное карабкание. Подъём идёт до положения, в котором верх персонажа сравнивается с крышей; затем игрок может подтянуться.
- Подкат использует `New animation/Running Slide.fbx`, отдельное состояние и низкий физический коллайдер. Вертикальное движение таза из клипа сохранено, горизонтальное перемещение задаёт физический контроллер. Под низким перекрытием персонаж остаётся в низком положении до выхода, после чего коллайдер возвращается к полному росту.
- Испытательная площадка содержит проход с просветом 1,05 м и длиной 3 м. Соседние крыши разнесены, чтобы их коллайдеры не пересекались.

Исходные FBX загружаются локально. Горизонтальный root motion исключён: перемещение персонажа выполняет физический контроллер. Для подката сохранена вертикальная часть root motion, чтобы модель действительно опускалась под перекрытие. Кувырок второго прыжка выполняется процедурно, поскольку отдельного подходящего скелетного клипа нет.

## Локальная разработка

Понадобится Node.js 20.19 или новее. В папке проекта выполните `npm install`, затем `npm run dev`. Для проверки версии, публикуемой на GitHub Pages: `npm run build -- --base=/Parkour_Game/`.

Основные файлы: `src/main.js` — интерфейс и ввод; `src/player.js` — контроллер; `src/animation.js` — клипы и смешивание; `src/level.js` — площадка и коллайдеры; `src/sound.js` — звуки. Звуковые эффекты — Kenney RPG Audio, лицензия в `public/assets/sounds/LICENSE.txt`.

## Текущие ограничения

- Позиционирование кистей у края основано на клипе и точке захвата. Отдельного IK для каждой руки пока нет, поэтому на сложных углах возможен визуальный зазор.
- Уровень собран из простых форм. Захват работает на отмеченных уступах этих форм; свободное лазание по произвольным сеткам не реализовано.
- Подкат визуально рассчитан на текущий просвет. При сильном изменении высоты перекрытия или параметров подката позу потребуется дополнительно настроить.
