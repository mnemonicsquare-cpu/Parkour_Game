# ParkourGame

Локальный браузерный прототип 3D-паркура. Персонаж — предоставленная в наборе анимаций модель **Y Bot.fbx**. Это единственная найденная модель персонажа: отдельного пользовательского героя среди переданных файлов нет.

## Играть в браузере

**[Открыть ParkourGame](https://mnemonicsquare-cpu.github.io/Parkour_Game/)**. Для игры по этой ссылке Node.js устанавливать не нужно. Первый запуск может занять немного времени: браузер загружает модель и анимации. Нажмите **Играть** в меню.

GitHub автоматически публикует новую версию после изменений в ветке `main`.

## Локальный запуск для разработки

1. Установите [Node.js](https://nodejs.org/) версии 20.19 или новее.
2. Откройте папку проекта в терминале и выполните `npm install` один раз.
3. Выполните `npm run dev`.
4. Откройте адрес, который покажет терминал (обычно `http://localhost:5173/`), и нажмите **Играть**.

После первого `npm install` игра работает локально без внешних игровых сервисов. Чтобы закрыть сервер, нажмите `Ctrl+C` в терминале. Для проверки готовой сборки: `npm run build`, затем `npm run preview`.

## Управление

| Клавиша | Действие |
|---|---|
| WASD | Движение относительно камеры |
| Мышь, колесо | Поворот и приближение камеры |
| Shift | Бег; перед подходящим препятствием — автоматический паркур |
| Space | Прыжок; повторное нажатие в воздухе — второй прыжок с кувырком; в висе — подтягивание |
| Ctrl | Включить или выключить скрытность |
| Shift + C у края | Перейти в вис для безопасного спуска |
| E в висе | Отпустить уступ |
| R | Вернуться к выбранной зоне |
| Esc | Пауза и меню |
| F3 | Диагностика и ручная проверка анимаций |

В меню можно выбрать одну из шести испытательных зон, изменить скорости, камеру, звук и основные клавиши.

В F3 также видны проволочная капсула персонажа, стрелка направления и голубые маркеры размеченных уступов.

## Реализовано

- Отдельные визуальная модель и физическое тело; капсула персонажа и упрощённые коллайдеры уровня.
- Физика Rapier на фиксированном шаге 1/60 секунды. Kinematic character controller выбран для отзывчивого движения, скольжения вдоль стен, шага через небольшие неровности и запросов к препятствиям. Гравитация и вертикальная скорость задаются игровым кодом.
- Ходьба, бег, плавное ускорение и поворот, диагональное движение без увеличения скорости.
- Прыжок с места и в движении, ограниченное управление в воздухе, coyote time и буфер прыжка по 0,1 с.
- Один дополнительный прыжок в воздухе с процедурным кувырком вокруг центра тела. После приземления возможность второго прыжка восстанавливается.
- Обычное приземление, кувырок при падении выше роста с горизонтальной скоростью, тяжёлое приземление выше настраиваемого порога 4,5 м.
- Автоматическое преодоление размеченных низких препятствий и захват размеченных высоких уступов; вис, боковое перемещение, подтягивание, отпускание. После захвата отпустите W, затем нажмите W или Space для подтягивания.
- Скрытность с уменьшенным коллайдером и проверкой свободного пространства перед выпрямлением.
- Камера от третьего лица с проверкой препятствий, меню, настройки, диагностика, локальные звуки шагов и действий.

## Анимационные ресурсы

Исходные FBX загружаются Three.js напрямую. Файлы из `Action Adventure Pack` содержат совместимые с Y Bot дорожки Mixamo; проверены загрузка и воспроизведение в браузере. Исходный рост модели при загрузке — 180,47 единицы FBX; для игры масштабирован до 1,8 м. Модель имеет вертикальную ось Y. Корневая дорожка `mixamorigHips.position` отключена, чтобы перемещение не применялось одновременно анимацией и физическим контроллером.

| Игровое действие | Файл | Длина, с | Использование |
|---|---|---:|---|
| Ожидание | `Action Adventure Pack/idle.fbx` | 3,90 | Цикл |
| Ходьба | `Action Adventure Pack/walking.fbx` | 1,03 | Цикл |
| Бег | `Action Adventure Pack/running.fbx` | 0,63 | Цикл |
| Начало прыжка | `Action Adventure Pack/jumping up.fbx` | 0,23 | Однократно |
| Полёт/падение | `Action Adventure Pack/falling idle.fbx` | 0,70 | Цикл |
| Кувырок | `Action Adventure Pack/falling to roll.fbx` | 1,47 | Однократно |
| Тяжёлое приземление | `Action Adventure Pack/hard landing.fbx` | 2,00 | Однократно |
| Переход в скрытность | `Action Adventure Pack/stand to cover.fbx` | 1,13 | Однократно; застывает в конечной позе |
| Движение в скрытности | `Action Adventure Pack/crouched sneaking left.fbx` | 1,27 | Цикл; исходно боковой шаг |
| Преодоление препятствия | `Stand To Roll.fbx` | 2,37 | Временный неподходящий клип; нужен vault |
| Подтягивание/вис | `Climbing Up Wall.fbx` | 2,00 | Временный клип; нет отдельных hang/pull-up |

`cover to stand.fbx` и `Climbing Down Wall.fbx` загружаются в панель ручной проверки, но пока не подключены к игровым переходам. Остальные предоставленные анимации сохранены в проекте для дальнейшего подбора.

## Известные ограничения

- Нет отдельных клипов для обычного приземления, висения, движения вдоль уступа, подтягивания, безопасного спуска и корректного преодоления препятствия. Соответствующие переходы используют близкие по смыслу клипы; анимационная точность пока ниже заявленной в техническом задании.
- Для кувырка при втором прыжке отдельного скелетного клипа нет: игровая модель делает процедурный оборот, пока проигрывается поза полёта.
- Свободное лазание по произвольным стенам отсутствует. Паркур работает только на размеченных препятствиях тестового уровня.
- Боковое движение в висе и подтягивание работают по упрощённой траектории. Сложные углы, навесы и неровные поверхности не проверены.
- Кувырок запускается только при достаточной горизонтальной скорости. Для вертикального падения выше роста пока используется обычная посадка до порога тяжёлой посадки.
- Отдельная анимация выпрямления после скрытности пока не проигрывается. Клип движения в скрытности представляет собой боковой шаг и может смотреться неточно при движении вперёд.
- Громкость окружения предусмотрена в настройках, но фонового аудиофайла среди выбранных ресурсов нет.
- GLB-конвертация и использование набора городских моделей не выполнены: прототип загружает FBX локально, уровень построен из простых форм.

## Что проверить вручную

Проверьте ощущения от ходьбы и бега с разными скоростями, прыжок с места и с разбега, сочетание Shift+Space, переход в скрытность и обратно, низкие препятствия, захват уступа и подтягивание, падения с площадок 1/2/3/5 м, работу камеры возле стен и смену зоны через меню. В F3 видны состояние контроллера, выбранный клип и физические показатели.

## Структура

- `src/main.js` — запуск, камера, ввод и интерфейс;
- `src/player.js` — состояния и движение персонажа;
- `src/animation.js` — загрузка и смешивание FBX-клипов;
- `src/level.js` — геометрия и физические коллайдеры;
- `src/sound.js` — звуковые события;
- `public/assets` — локальные модель, анимации и звуки.

Звуковые эффекты — Kenney RPG Audio, лицензия приложена в `public/assets/sounds/LICENSE.txt`.
